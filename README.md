# نظام إدارة ومتابعة العملاء المحتملين - Smart Address Egypt CRM

نظام متكامل واحترافي لإدارة وتأهيل ومتابعة العملاء المحتملين لشركة **Smart Address Egypt** (خدمات العناوين والمقرات الافتراضية وباقات قاعات الاجتماعات وغرف ورش العمل في مصر).

---

## 🌟 مميزات النظام الأساسية

1. **واجهة عربية كاملة بنسبة 100% (RTL)**: مصممة خصيصاً لشركات الـ B2B في مصر وبطابع وأسلوب عمل احترافي وهادئ، مع الحفاظ على أسماء الأعمدة وقيم البيانات الأصلية باللغة الإنجليزية في قاعدة البيانات.
2. **مركز استيراد متطور لملفات Excel و CSV**:
   - يدعم صيغ `.xlsx` و `.xls` و `.csv` مع ميزة السحب والإفلات (Drag & Drop).
   - إمكانية **لصق الجداول مباشرة من إكسيل (Copy & Paste / Ctrl+V)**.
   - التعرف الذكي والتلقائي على 23 عموداً باختلاف التسميات والمسافات والحروف الكبيرة والشرطات السفلية.
   - مراجعة وتعديل مطابقة الأعمدة يدوياً قبل الاعتماد.
   - التحقق من تكرار العملاء برقم الهاتف أو البريد الإلكتروني مع خيارات: (تحديث البيانات السابقة دون مسح الملاحظات، أو تخطي المكرر).
   - تنسيق وضبط أرقام الهواتف المصرية تلقائياً (+2010 / 011 / 012 / 015).
   - سجل تاريخي لجميع عمليات الاستيراد السابقة لتدقيق العمليات.
3. **محرك تقييم ذكي وشفاف (Lead Scoring Engine 0-100)**:
   - يحسب الجدية بناءً على: توقيت البدء (فوراً vs خلال شهر vs بعد 3 شهور)، نوع الباقة المطلوبة، اكتمال بيانات الاتصال، وجودة العميل في الحملة الإعلانية.
   - **قاعدة الأولوية للردود السلبية**: الرد الصريح بعدم الاهتمام (مثل "غير مهتم"، "رفض"، "غالي") يخفض النقاط فوراً إلى 15 نقطة وينقل العميل للمستبعدين لتوفير وقت مسؤولي المبيعات.
   - تصنيف الأولويات: **ساخن (80-100)**، **دافئ (60-79)**، **تغذية ومتابعة دورية (35-59)**، **منخفض (0-34)**.
4. **توصيات ذكية ومسودات واتساب باللهجة المصرية التجارية**:
   - نصائح عملية لكل عميل توضح: ماذا تقول له في المكالمة، القناة المقترحة (اتصال هاتفي أم واتساب)، والخطوة التالية.
   - تجهيز رسالة واتساب مخصصة جاهزة للإرسال بنقرة واحدة عبر `wa.me`.
5. **مساحة متابعات اليوم (Daily Sales Cockpit)**:
   - 6 أقسام تفاعلية: (متابعات متأخرة، مكالمات اليوم، عملاء ساخنون لم يتم التواصل معهم، عملاء بانتظار الرد، متابعات قادمة خلال الأسبوع، مراجعة قبل الإلغاء).
   - نافذة سريعة لتسجيل نتائج المكالمات (لم يرد، مهتم، طلب تأجيل، تعاقد 🏆، إلخ).
6. **مراحل البيع (Pipeline Kanban Board)**:
   - لوحة كانبان لنقل العملاء بين مراحل البيع.
7. **لوحة تحكم وتحليلات تفاعلية (Interactive Charts)**:
   - إجمالي العملاء، الصفقات الرابحة، معدل التحويل اللحظي، توزيع جودة العملاء، تحليل أداء الحملات والمنصات (Facebook / Instagram Ads)، وأسباب خسارة الصفقات.
   - النقر على أي بطاقة أو رسم بياني ينقلك مباشرة للعملاء المطابقين.
8. **قاعدة بيانات دائمة وآمنة (SQLite Persistent DB)**:
   - حفظ كامل لكافة التعديلات والملاحظات وتاريخ الأنشطة في ملف `smart_address_crm.db`.
   - لا تفقد البيانات عند تحديث المتصفح، مع إمكانية التصدير الكامل لنسخة احتياطية JSON و Excel.

## 🚀 كيفية تشغيل واستخدام النظام

### 1. الرابط المباشر
الخادم يعمل حالياً على جهازك محلياً عبر الرابط:
👉 **[http://localhost:3456](http://localhost:3456)**

### 2. إعادة تشغيل الخادم في أي وقت
يمكنك النقر المزدوج على ملف:
`C:\Users\Youssef\.gemini\antigravity-ide\scratch\smart-address-crm\start_crm.bat`

أو تشغيله عبر الطرفية (PowerShell):
```powershell
& "C:\Users\Youssef\AppData\Roaming\Antigravity\bin\agy-node.cmd" server.js
```
